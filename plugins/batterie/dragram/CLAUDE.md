# dragram

Diagrams a person drags and Claude reads: boxes move in the browser under `?edit`, every drop is written back into the `.html` file, connectors follow live geometry, and `shot.py --state` checks the result in a real browser. The `dragram` skill (`skills/dragram/SKILL.md`) is the how-to; the `diagram` skill covers static SVG diagrams.

This file ships in the public batterie plugin, so it stays short and general. The working notes for developing dragram itself live in DEVELOPING.md, which stays in the private source repo:
